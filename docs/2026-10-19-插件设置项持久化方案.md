# 插件设置项持久化方案

## 1. 背景与目标

当前 `config.ini` 只保存应用级配置（`[general]` language/theme、`[window]` geometry/state、`[nav]` order/hidden、`[meta]` config_version），全部经 `common/app_settings.py` 的 `AppSettings` 统一读写。各插件设置卡片（`settings_card`）里的滑块、下拉框、复选框、输入框每次启动都硬编码重置，不落盘——用户每次重启都要重新调到自己习惯的值。

目标：

1. **每个插件的可配置项都保存到同一个 `config.ini`**，记住用户习惯。
2. **统一通过一个公共方法**读写，避免每个插件各写一套 `set/get` 与类型转换。
3. **设置页「恢复默认设置」**能清空全部配置项（含插件设置），让所有控件回到硬编码默认值。

## 2. 非目标

- 不持久化文件列表（`FileListPanel` 的内容是会话级数据）。
- 不做运行时「即时落盘」——不监听滑块 `valueChanged` 逐次写盘（太碎、影响性能）。落盘时机统一在窗口关闭时，与现有 `save_geometry` 一致；崩溃丢失可接受，与窗口几何同风险等级。
- 不改 `config.ini` 的存储位置、原子写、备份机制——沿用 `AppSettings`。

## 3. INI 结构

`config.ini` 分两个命名空间：**全局项收进 `setting.*`**（v2 起由原 `[general]`/`[window]`/`[nav]`/`[meta]` 平铺节迁移而来），**插件项占 `plugin.<id>` 节**——节名即前缀，天然区分归属。`id` 取 `config.py` 的 `PLUGIN_MODULES` 中注入的稳定 id：

```ini

[setting.window]

[setting.nav]

[setting.meta]

[plugin.image_compressor]

[plugin.pdf_merger]

[plugin.pdf_splitter]

[plugin.file_deduplicator]

use_trash = 1

```

类型约定：

- 整数（spinbox、slider、combo 的 int data）→ `str(int)`，读取时 `int(raw)`。
- 布尔（checkbox）→ `"1"` / `"0"`，读取时 `raw in ("1","true")`。
- 字符串（combo 的 str data、output 路径）→ 原样存储。
- 缺键或解析失败 → 回退硬编码默认值，不抛异常。

## 4. 公共方法（ToolPlugin 基类）

在 `toolbox.py` 的 `ToolPlugin` 基类上新增一组共享方法，作为所有插件读写配置的唯一入口。插件只需覆写两个钩子：`load_settings()`（读 INI → 应用到控件）和 `save_settings()`（读控件 → 写 INI）。基类默认实现为空操作，不需要持久化的插件（如 `empty_folder_cleaner`）无需任何改动。

```python
# ToolPlugin 基类新增

def app_settings(self):
    """返回父窗口的 AppSettings，无则 None（与 SettingsPlugin._settings_ref 同源）"""
    return getattr(self.parent, "app_settings", None)

def _settings_section(self):
    return f"plugin.{self.id}"

def load_setting(self, key, default=None, type=str):
    """读取本插件配置项；缺键或类型转换失败时返回 default"""
    settings = self.app_settings()
    if settings is None:
        return default
    raw = settings.get(self._settings_section(), key, None)
    if raw is None or raw == "":
        return default
    try:
        if type is bool:
            return str(raw).strip().lower() in ("1", "true", "yes", "on")
        return type(raw)
    except (ValueError, TypeError):
        return default

def save_setting(self, key, value):
    """写入本插件配置项（仅内存，不落盘；由窗口统一 save）"""
    settings = self.app_settings()
    if settings is None:
        return
    settings.set(self._settings_section(), key, str(value))

def set_combo_by_data(self, combo, value):
    """按 data 匹配下拉框选项（兼容 int/str data，匹配 str 形式）"""
    for i in range(combo.count()):
        if str(combo.itemData(i)) == str(value):
            combo.setCurrentIndex(i)
            return

# 钩子：子类覆写
def load_settings(self):
    """启动时与恢复默认后由框架调用——把 INI 值应用到控件"""

def save_settings(self):
    """窗口关闭前由框架调用——把控件值写入 INI（仅 set，不 save）"""

def reset_settings(self):
    """清空本插件 INI 节并重新加载默认值"""
    settings = self.app_settings()
    if settings is not None:
        settings.remove_section(self._settings_section())
        settings.save()
    self.load_settings()
```

要点：

- `load_setting` / `save_setting` 就是用户要求的「公共大的方法」——所有插件统一走它，类型转换与异常处理集中在基类，插件代码只剩「哪个控件 ↔ 哪个键」的映射。
- `save_setting` 不调 `save()`，避免 N 个插件各写一次盘；由 `ToolboxWindow.closeEvent` 统一调一次 `app_settings.save()`。

## 5. AppSettings 改动

`common/app_settings.py` 新增一个公共方法（供 `reset_settings` 用）：

```python
def remove_section(self, section):
    """删除指定节；不存在则无操作"""
    if self._parser.has_section(section):
        self._parser.remove_section(section)
```

`reset()` 已经重建空 parser，天然清掉所有 `plugin.*` 节，无需改动。

## 6. ToolboxWindow 接线

### 6.1 注册插件后加载设置

`register_plugin` 在 `plugin.get_widget()` 成功后调用 `plugin.load_settings()`，让保存值覆盖 `create_ui` 里的硬编码默认：

```python
widget = plugin.get_widget()
# ... scroll_area 装配 ...
try:
    plugin.load_settings()
except Exception as e:
    print(f"加载插件设置失败 {plugin.id}: {e}")
```

### 6.2 关闭时保存全部插件设置

`closeEvent` 现有逻辑只调 `save_geometry()`。新增 `save_plugins_settings()` 在其之前执行，把各插件 `set()` 到内存，再由 `save_geometry()` 末尾的 `save()` 一次性落盘（一次磁盘写）：

```python
def closeEvent(self, event):
    self.save_plugins_settings()
    self.save_geometry()
    event.accept()

def save_plugins_settings(self):
    for plugin in self.plugins.values():
        try:
            plugin.save_settings()
        except Exception as e:
            print(f"保存插件设置失败 {getattr(plugin, 'id', '?')}: {e}")
```

### 6.3 恢复默认时重载各插件

`SettingsPlugin.reset_defaults` 在 `self._settings_ref.reset()` 之后，除现有的导航/主题/语言/几何复位外，再遍历所有插件调 `load_settings()`，让控件回到硬编码默认（此时 INI 已清空，`load_setting` 全部回退 default）：

```python
# 恢复各插件设置到默认值
for plugin in getattr(self.parent, "plugins", {}).values():
    try:
        plugin.load_settings()
    except Exception as e:
        print(f"重置插件设置失败 {getattr(plugin, 'id', '?')}: {e}")
```

## 9. 配置保存时机（完整记录）

所有配置的**读取与写入时机**一览（也是 `CLAUDE.md`「Configuration Persistence」一节的依据）：

| 配置项 | 读取时机 | 写入时机 | 写盘方式 |
|--------|----------|----------|----------|
| `[setting]` language | `main.py` 启动（QApplication 后、窗口前） | 语言下拉变化 | 立即 `save()` |
| `[setting]` theme | 窗口构造（初始主题） | 主题按钮点击 | 立即 `save()` |
| `[setting.window]` geometry/state | 窗口构造 `load_geometry()` | `closeEvent` → `save_geometry()` | 随链路 `save()` |
| `[setting.nav]` order/hidden | `rebuild_navigation()` | 导航管理操作 | 立即 `save()` |
| `[plugin.<id>]` 全部 | `register_plugin` → `load_settings()` | `closeEvent` → `save_plugins_settings()` | 仅 `set`，随 `save_geometry` 的 `save()` 一次落盘 |

**插件设置的保存时机规则**：

1. **改控件不落盘**——拖滑块、切下拉、勾选框、改路径都只改控件内存，不触发任何写盘。
2. **唯一落盘点是窗口正常关闭**——`ToolboxWindow.closeEvent` 先 `save_plugins_settings()`（各插件把控件值 `set` 进内存 parser），再 `save_geometry()`（末尾 `app_settings.save()` 一次性把全部改动原子写入）。整个关闭流程只发生**一次**磁盘写。
3. **崩溃/强杀丢失**——上次正常关闭之后的插件设置改动会丢，与窗口几何同风险等级，属有意设计（避免高频写盘）。
4. **恢复默认即落盘**——设置页「恢复默认设置」调 `AppSettings.reset()` 重建空配置（清掉 `setting.*` 与全部 `plugin.*`）并立即写盘，随后遍历各插件 `load_settings()` 让控件回到 `create_ui` 中的硬编码默认。
5. **即时 `save()` 仅限全局项**——语言、主题、导航这类低频显式操作在动作发生时立即写盘；插件设置项跟随关闭时机。新增配置项时应按此归属选择写入时机。
