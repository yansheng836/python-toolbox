# 空文件夹清理插件设计

## 目标

新增独立插件，递归查找用户选定根目录下可删除的递归空目录。目录树中不能存在文件、隐藏项、符号链接或其他非目录条目；只包含递归空子目录的目录也算递归为空。若连续多层目录均为空，只展示并标记最上层目录，删除时递归移除该候选目录及其空子目录。用户选择的扫描根目录始终保留。

## 用户流程

1. 用户选择一个根目录，或将目录拖入输入框。
2. 后台线程递归扫描目录，UI 展示可删除的最上层空目录路径。
3. 用户勾选一项或多项并点击删除；删除前显示确认信息和目录列表。
4. 后台线程按目录深度自底向上调用 `os.rmdir`。它只移除当时仍为空的候选目录及其子目录，因此扫描后新建的文件不会被删除；受占用或权限限制的目录作为失败项报告。

扫描根目录不会出现在结果列表中，也不会被插件删除。扫描遇到符号链接时将其视为内容，不跟随链接遍历。

## 架构

新增 `plugins/empty_folder_cleaner.py`，提供 `EmptyFolderCleaner` 插件、负责目录扫描/删除的 `BaseWorker` 子类，以及承载 UI 的 QWidget。插件复用 `DirectoryDropLineEdit` 的目录拖入交互思路、`ActionPanel`、`Card`、`AnimatedButton`、`SelectableLabel` 和主题常量；结果列表支持多选，并按路径显示待删除目录。扫描和删除均在后台线程执行，主线程更新进度与结果。

在 `config.py` 的 `PLUGIN_MODULES` 注册插件，并在 `toolbox.spec` 的 `hiddenimports` 添加动态导入模块。

## 扫描与删除语义

扫描以根目录为边界，使用不跟随符号链接的目录遍历。目录仅当其整棵子树不存在文件、隐藏项、符号链接或其他非目录条目时才是递归空目录。结果采用最上层递归空目录：若某目录的父目录也位于扫描根目录之下且递归为空，则只输出更高层父目录。根目录不作为结果候选，但勾选的候选目录本身会被删除。

删除前对用户勾选的每个候选目录进行再次处理。删除实现只尝试移除目录，不递归删除文件；从候选目录的叶子向上逐级 `os.rmdir`，遇到非空或不可访问目录时记录失败并继续其他候选项。删除完成后向用户报告成功与失败数量及失败路径。

## 验证

新增自动化测试覆盖：

- 空目录以及多层空目录仅返回最上层候选，递归删除后子目录消失。
- 含普通文件、点开头隐藏文件或符号链接的目录不会作为空目录返回。
- 根目录自身为空时仍然保留。
- 候选目录在扫描后增加文件时，删除不移除该文件且报告目录未能删除。
- 插件注册、UI 创建和主题切换符合现有测试约定。
- 更新后的 Python 文件通过 `py_compile` 和 pyflakes 检查；配置文件通过语法校验；打包配置包含插件模块。
