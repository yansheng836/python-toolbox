# P3 插件层 i18n 迁移实施计划

> **For agentic workers:** 按插件文件并行派发 agent（文件互不相交），每个 agent 只改自己的插件文件 + 新建自己的测试文件，pathspec 限定提交。

**Goal:** 9 个插件（image_compressor / image_format_converter / image_scaler / image_stitcher / image_to_pdf / pdf_merger / pdf_splitter / file_deduplicator / empty_folder_cleaner）的用户可见中文全部改走 `common.i18n.t()`，组合框用 `bind_combo` 保持稳定 data，实现 `retranslate_ui()` 支持运行时语言切换。

**Architecture:** zh_CN.json（382 键）已在 P0 阶段逐字提取，key 覆盖齐全；P2 已建立 `retranslate_ui` 信号链路（ToolboxWindow.retranslate_ui → 每个 plugin.retranslate_ui）。P3 只需把插件文本接到既有 key 上。

**Tech Stack:** PyQt6、common/i18n.py（t/bind/bind_combo）、pytest。

## Global Constraints

- 显示文本逐字不变：t() 的 key 必须对应 zh_CN.json 中与原文完全一致的值。
- 缺失 key 不要自行改 zh_CN.json（并行冲突），在报告中列出，由控制者统一补。
- worker 消息用 t()（纯字典查找，线程安全）；f-string 改命名占位符。
- 组合框：`bind_combo(combo, [(key, stable_data), ...])`，业务逻辑仍用 currentData()。
- 文件对话框过滤器/标题、占位符、对话框标题与消息全部接入。
- 每个插件实现 `retranslate_ui()`：重放标题/描述/标签/按钮/占位符/组合框（bind_combo 自动）。
- `_setup_header` 的标题/描述来自 config 注入的 self.name/description → retranslate 用 `t(f"plugin.{id}.name")` / `t(f"plugin.{id}.description")`，标题保持 `f"{self.icon} {name}"` 格式。
- 遵循 CLAUDE.md：UTF-8 LF + 编码行 + docstring、SelectableLabel、Theme.*、py_compile/pyflakes、只跑本插件测试。
- 提交 pathspec 限定：只含 `plugins/<file>.py` 与 `test/test_p3_<id>.py`。
