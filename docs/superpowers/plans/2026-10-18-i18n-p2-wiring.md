# P2 启动集成与语言切换实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 i18n 基础设施接入应用：main.py 启动顺序按设计文档 §7.3，配置/几何持久化从注册表切换到 config.ini，主框架文本走 t() 词典并支持运行时语言切换，设置页新增语言下拉。

**Architecture:** AppSettings（INI）在 main.py 创建后传给 ToolboxWindow；i18n.set_language 在窗口构造前调用（构造即正确语言）；运行期切换由 language_changed 信号 → ToolboxWindow.retranslate_ui() → 各插件 retranslate_ui()。语言选择持久化到 INI 的 [general] language。

**Tech Stack:** PyQt6、configparser（AppSettings）、common/i18n.py（LanguageManager/bind/bind_combo）。

## Global Constraints

- 启动顺序（§7.3）：QApplication → setup_app_identity → AppSettings → migrate_from_qsettings → i18n.set_language → install_qt_translator → ToolboxWindow。**migrate 必须紧跟 AppSettings 构造**（评审 M3：首次构造后 _explicit_keys 为空才可导入注册表值）。
- 启动加载绝不覆盖已保存值（反 init_theme bug）：init_theme 读 INI theme，不写回。
- 迁移 geometry/windowState 用 base64（bytes_to_qbytearray 还原），勿 str(QByteArray)（评审 I1）。
- 语言切换流程（§6.3）：INI 写入 → i18n.set_language → language_changed → ToolboxWindow.retranslate_ui → 每个 plugin.retranslate_ui()。
- 显示文本一律走 zh_CN.json 既有 key（382 键）；新增 key 需同步 zh_CN.json 并跑 check_i18n.py。
- CLAUDE.md 全部规则适用（py_compile/pyflakes、UTF-8 LF、Theme.*、SelectableLabel、响应式布局、只测代码改动）。
- **工作区有并行会话在翻译 docs/*.md**——所有提交必须 pathspec 限定，勿碰 *.md。
