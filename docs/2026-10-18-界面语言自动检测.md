# 界面语言自动检测

> 日期：2026-10-18。状态：已实现。
> 需求：启动时检查系统语言并自动设置界面语言，首次自动设置后弹窗告知用户；若不符合预期，可到设置页手动切换。

## 背景

修改前，启动语言固定读取 `config.ini` 的 `general.language`，缺失时使用默认值 `zh_CN`。英文系统用户首次运行会直接看到中文界面，需要自行到设置页切换。

## 设计决策

| 方案 | 说明 | 结论 |
|---|---|---|
| 仅首次启动检测 | 配置中尚无用户选择时按系统语言初始化并写回配置，之后以用户选择为准 | 采用 |
| 每次启动跟随系统 | 需额外记录“是否手动选择”，系统语言变化会覆盖用户选择 | 未采用 |
| 增加“跟随系统”下拉项 | 语言下拉框新增第三项，改动与文案成本更大 | 未采用 |

关键约束：`AppSettings.load()` 在首次启动时会把默认值 `language=zh_CN` 立即落盘，因此不能仅凭“键存在”判断用户是否选择过。`load()` 读取已有文件时会把文件中的键记入 `_explicit_keys`，而默认值填充不会记入，故可用它区分“已保存值”与“默认值”。

## 实现

### 1. 系统语言检测（`common/i18n.py`）

```python
def detect_system_language():
    if QLocale.system().name().startswith("zh"):
        return "zh_CN"
    return "en"
```

- 中文各变体（`zh_CN` / `zh_TW` / `zh_HK` 等）统一映射到唯一的中文词典 `zh_CN`
- 其他语言一律回退到 `en`（当前仅支持 `zh_CN` / `en` 两种界面语言）

### 2. 区分已保存值与默认值（`common/app_settings.py`）

新增 `is_explicit(section, key)`：键来自配置文件或 `set()` 时返回 `True`，由 `_fill_defaults()` 填充的默认值返回 `False`。

### 3. 启动语言决策（`main.py`）

`resolve_startup_language(settings)` 返回 `(语言代码, 是否首次自动检测)`：

- `is_explicit` 为 `True` → 直接沿用保存值
- 否则 → 调用 `detect_system_language()`，把结果写入 `general.language` 并 `save()`；写入失败仅打印警告，不阻塞启动
- 启动顺序保持不变：`AppSettings` → `migrate_from_qsettings()` → 语言决策 → `set_language()` → 安装 qtbase 翻译器 → 创建窗口

### 4. 首启弹窗（`main.py`）

窗口 `show()` 之后，若本次语言为自动检测结果，使用 `MessageUtils.show_info()` 弹出提示，并传入窗口当前主题：

> 检测到系统语言为「简体中文」，已自动为您设置界面语言。
> 如不符合预期，请到设置页手动切换语言。

弹窗只在首次自动检测的那一次启动出现；语言写入配置后，后续启动不再检测，也不再弹窗。

### 5. 新增词条

| key | zh_CN | en |
|---|---|---|
| `settings.dialog.auto_language_title` | 界面语言 | Interface Language |
| `settings.dialog.auto_language_message` | 检测到系统语言为「{language}」，已自动为您设置界面语言。\n如不符合预期，请到设置页手动切换语言。 | Detected system language: {language}. The interface language has been set automatically.\nIf this is not expected, please change it manually on the Settings page. |

同步写入 `i18n/zh_CN.json`、`i18n/en.json` 与 `i18n/fragments/toolbox.json`。

### 6. 主题适配（`toolbox.py`）

`ToolboxWindow` 新增只读属性 `current_theme`，供弹窗使用当前主题样式，避免深色界面下弹出浅色对话框。

## 行为边界

| 场景 | 行为 |
|---|---|
| 全新安装（无 `config.ini`） | 按系统语言初始化并弹窗提示 |
| 配置已有 `language` 键（含旧版本默认写入的 `zh_CN`） | 沿用保存值，不检测、不弹窗 |
| 系统为中文（任意地区） | `zh_CN` |
| 系统为英文 | `en` |
| 系统为其他语言 | `en` |
| 配置文件不可写 | 使用检测结果启动，打印警告，下次启动重新检测 |

> 说明：旧版本首次启动时已把默认值 `language=zh_CN` 写入配置，历史配置无法区分“用户选择”与“默认填充”。按约定，已有保存值的配置保持原样；如需验证首启检测，删除配置中的 `language` 行后重启即可。
