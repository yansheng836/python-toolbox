# i18n key 命名与中文提取规范

> 日期：2026-10-18。目标：在改代码之前，把**所有用户可见的中文文本**逐字提取到 JSON，固化中文原文。
> 本阶段只写 JSON fragment（`i18n/fragments/*.json`），不改任何代码，不翻译；fragment 合并为 `i18n/zh_CN.json` 后随代码改动一起提交。

## 产出物

每个 agent 写自己的 fragment 文件（UTF-8、LF、单个 JSON 对象、不含注释）：

```text
i18n/fragments/toolbox.json         # agent A
i18n/fragments/common.json          # agent B
i18n/fragments/config.json          # agent C
i18n/fragments/plugins_misc.json    # agent C（pdf_merger/pdf_splitter/empty_folder_cleaner）
i18n/fragments/plugins_batch1.json  # agent D（image_compressor/image_stitcher/file_deduplicator）
i18n/fragments/plugins_batch2.json  # agent E（image_scaler/image_to_pdf/image_format_converter，后补）
```

格式：扁平对象，`"key": "中文原文"`。值必须**逐字保留**原文（含冒号、括号、空格、emoji、标点）。省略号用原文的写法（`...` 或 `…`，照抄）。

## 收录范围

- **收录**：窗口标题、菜单、托盘、侧边栏、按钮、卡片标题、表单标签、复选框文字、下拉项显示文本、占位符、表格表头、文件对话框标题与过滤器、进度/状态/成功/警告/错误消息、worker 生成的消息、表格单元格内的固定文本（如"未知"）。
- **不收录**：`print()` 控制台日志、docstring、注释、纯 emoji、URL、第三方库返回的原文。

## key 命名规范

全小写 snake_case，点分层级，前缀按归属（跨 fragment 全局唯一）：

| 前缀 | 归属 | 示例 |
|---|---|---|
| `app.*` | 应用信息（config.py） | `app.name`、`app.window_title`（值 `"工具箱 v{version}"`） |
| `welcome.*` | 欢迎页（config.py 的 WELCOME_CONFIG） | `welcome.subtitle` |
| `menu.*` / `tray.*` / `sidebar.*` | toolbox.py 主框架 | `menu.file`、`tray.quit`、`sidebar.home` |
| `settings.*` | toolbox.py 内置设置页 | `settings.theme_label` |
| `common.*` | common/ 下组件内部文本 | `common.filter.all_files`、`common.cell.unknown` |
| `column.*` | 表格列显示名 | `column.filename`、`column.dimensions` |
| `plugin.<id>.*` | 各插件文件内文本 | `plugin.image_compressor.label.format` |

`<id>` 用 config.PLUGIN_MODULES 的稳定 id（image_compressor / image_format_converter / image_stitcher / image_to_pdf / image_scaler / pdf_merger / pdf_splitter / file_deduplicator / empty_folder_cleaner / settings）。

**key 后缀动词规范**（保持一致，便于检索）：

| 后缀 | 用途 | 示例 |
|---|---|---|
| `.name` / `.description` | 插件名/描述（**只由 config.json 收录一次**） | `plugin.image_compressor.name` |
| `.title` | 页面/窗口标题 | `plugin.pdf_merger.title`（一般由 header 渲染，无需收录） |
| `.card.*` | Card 标题 | `plugin.image_compressor.card.select_images` |
| `.label.*` | 表单标签（含冒号照抄） | `plugin.image_compressor.label.quality` |
| `.button.*` | 按钮 | `plugin.image_compressor.button.browse` |
| `.checkbox.*` | 复选框 | `plugin.image_to_pdf.checkbox.compress` |
| `.combo.<data值>` | 下拉项显示文本（data 值来自 P0.5 的稳定值） | `plugin.image_compressor.combo.keep` = `"保持原格式"`；`plugin.image_scaler.combo.width` = `"指定宽度"` |
| `.placeholder.*` | 占位符 | `plugin.image_compressor.placeholder.output_dir` |
| `.filter.*` | 文件对话框过滤器 | `plugin.pdf_merger.filter.pdfs` |
| `.dialog.*` | 对话框标题 | `plugin.image_to_pdf.dialog.save_pdf` |
| `.msg.*` | 进度/状态/成功消息 | `plugin.image_compressor.msg.compress_done` |
| `.warning.*` / `.error.*` | 警告/错误 | `plugin.image_compressor.error.compress_failed` |
| `.column.*` | 去重树等表格内列（插件自有） | `plugin.file_deduplicator.column.path` |

## 占位符规则

- 命名占位符，snake_case，语义自明：`{count}` `{total}` `{name}` `{path}` `{error}` `{dir}` `{pages}` `{index}` `{version}`。
- f-string 转换示例：
  - `f"成功压缩 {processed} 张图片！"` → `"成功压缩 {count} 张图片！"`（key `.msg.compress_done`）
  - `f"正在处理: {os.path.basename(file_path)}"` → `"正在处理: {name}"`（key `.msg.processing`）
  - `f"压缩失败: {str(e)}"` → `"压缩失败: {error}"`（key `.error.compress_failed`）
- 拼接句（如 `msg += f"\n（已跳过 {skipped} 张损坏图片）"`）拆成独立 key，换行符照抄在值里。
- **复数**：一律用纯字符串 + `{count}`；不在本阶段引入 `{one/other}` 结构（后续英文需要时再统一升级）。

## 漂移核对

P0.5 重构已改动部分文件（image_compressor / image_stitcher / file_deduplicator / common/* / config.py / toolbox.py）。如发现当前 HEAD 与基线提交 `622da18` 中**同一 UI 元素**的中文文本不一致，以 `622da18` 为准收录，并在报告中列出差异。（评审已确认显示文本未变，预期无差异。）

## 分工边界（防重复收录）

- 插件页头标题/描述由 `_setup_header` 渲染 `self.name/self.description`（来自 config.py）——**只在 config.json 收录**，插件 fragment 不重复收录。
- combo 显示文本：data 稳定值已在代码里，fragment 收录"显示文本"，key 后缀用 data 值（见 `.combo.<data值>`）。
- 列名：`common.json` 收录 `column.*`（IMAGE/PDF_COLUMNS + created/modified）。

## 校验

写完 fragment 后运行 `python -m json.tool <file>` 确认合法；在报告中给出：收录条数、key 清单摘要、拿不准的条目（归到哪个 key、是否收录）。
